# Freya's Magical English Adventure 🦄🎀

A delightful, interactive English conversation learning web app designed for **Freya Shyam**, featuring Hello Kitty, Unicorns, pastel colors, natural voice text-to-speech audio, and full **Bahasa Indonesia** translation support.

Based on the 11 chapters of *"Spoken English in Dialogues"* by Julia Deniskina:
1. 🤝 Good Manners (Sopan Santun)
2. 🏙️ Going to Public Places (Tempat Umum)
3. 🎉 Social Interaction (Berkenalan & Bertamu)
4. 🛒 Shopping (Belanja)
5. ✈️ Air Travel (Naik Pesawat)
6. 🔑 Car & Flat Rental (Sewa Mobil & Rumah)
7. 🏨 Staying in a Hotel (Menginap di Hotel)
8. 🩺 Seeing a Doctor (Periksa ke Dokter)
9. 🍽️ Eating Out (Makan di Restoran)
10. 🚨 Problems & Emergencies (Mengatasi Masalah)
11. 📞 Telephoning (Menelepon)

## Live Web App
Open `index.html` directly in any web browser, or host on GitHub Pages!
